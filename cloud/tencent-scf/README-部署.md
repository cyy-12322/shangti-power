# 腾讯云函数 SCF 部署指南 v2.0（定时推送 + 微信问答）

> 一个函数干两件事：
> 1. **每天 10:00 和 20:00** 自动推送电量到微信（PushPlus）
> 2. 你在**自己的订阅号**里发「查电费」，1 秒内回你当前电量（被动回复，免费）
>
> 全程 ¥0，不依赖电脑开机。代码零 npm 依赖。

## 4. 定时触发器（10:00 / 20:00）

触发管理 → 创建触发器：

| 项 | 填什么 |
| --- | --- |
| 触发方式 | 定时触发 |
| 名称 | `power-daily` |
| **Cron 表达式** | **`0 0 10,20 * * * *`** |
| 启用 | 是 |

> 7 段式：**秒 分 时 日 月 星期 年**，按**北京时间**解释。
> `0 0 10,20 * * * *` = 每天 10:00 和 20:00。
> 注意：秒和分都是 0，第三个字段才是小时。

## 5. 开启「函数 URL」（微信问答的入口）

函数详情 → **函数管理 → 函数 URL** → 点击**启用/新增**：

| 项 | 填什么 |
| --- | --- |
| 协议 | **HTTPS** |
| 是否启用 | 是 |
| 响应集成 | 保持默认（不需要开） |

创建后会得到一个地址，形如：

```
https://xxxxxxxxxxxxxxxx.ap-shanghai.tencent-scf.com/
```

**先把它复制下来**，第 7 节要填到微信后台。用浏览器打开应该返回 `invalid signature`（说明函数在正常响应，只是没带微信的签名参数，属于预期）。

## 6. 注册个人订阅号（免费，约 5 分钟）

5. **选择主体类型：个人**

> 个人主体**无法微信认证**（个人不能认证），所以：**不能主动推送消息**、被动回复有 5 秒时限。
> 对我们没影响：定时推送走 PushPlus，问答走被动回复。

## 7. 订阅号接入（服务器配置）

登录 https://mp.weixin.qq.com/ → 左侧 **设置与开发 → 基本配置**：

1. 找到 **「服务器配置」** → 点 **修改配置**
2. 按下表填：

| 字段 | 填什么 |
| --- | --- |
| URL | 第 5 节拿到的**函数 URL**（https 开头，注意结尾斜杠有无要与实际一致） |
| Token | 和第 2 节环境变量 `WECHAT_TOKEN` **完全一致**的那串（如 `mytoken123`） |
| EncodingAESKey | 点「随机生成」 |
| **消息加解密方式** | **明文模式** ⚠️（选兼容/安全模式需要在代码里做 AES 解密，没必要） |

3. 点 **提交**。微信会立刻向该 URL 发一个 GET 请求验证：
   - 成功：提示「提交成功」
   - 失败：检查 ① 函数 URL 是否 HTTPS 可访问 ② 环境变量 `WECHAT_TOKEN` 是否与网页上填的一致 ③ 函数是否已部署
4. 提交成功后，把 **「服务器配置」的启用开关打开**
5. 到 **「自动回复」** 页面，把「关键词自动回复 / 收到消息回复」里的规则**清空或删除**——否则微信会抢答，我们的函数就不会被调用

## 8.5 点了「测试」能收到，但**定时不发消息**？按这个顺序查

> 「测试」和「定时」走的是同一段推送代码，区别只在**触发器**。所以测试成功 = 代码和推送都没问题，问题必然在触发器配置。

1. **有没有触发器**：函数详情 → **触发管理**，列表里必须有一条「定时触发器」。没有就点「创建触发器」。
2. **触发器是否启用**：状态要是「已启用」。停用了不会触发。
3. **Cron 是 7 段式**：`0 0 10,20 * * * *`（秒 分 时 日 月 星期 年）。
   - 写成 5 段（linux crontab 习惯）→ 腾讯云会拒绝或永不触发
   - 小时字段写错（比如写成 `0 10,20 * * * *`）→ 触发时间完全不对
4. **函数代码改过是否点了「部署」**：不点部署，跑的还是旧版本。
5. **看「上次触发时间」**：如果是 `-`，说明从没触发过 → 基本就是 1/2/3 之一。
6. **时区**：定时触发器按**北京时间（UTC+8）**解释；把函数运行时的时区也设为 UTC+8，日志时间才和触发时间对得上。
7. **日志查询**搜 `[timer]`：
   - 有 `[timer] ... 定时推送` → 触发了，问题在推送（看 `[push]` 那行返回码）
   - 没有 → 就是没触发，回到 1/2/3
8. **改完等 1–2 分钟**再观察；腾讯云调度偶尔有几十秒延迟。
9. 账号欠费/风控会让函数暂停，控制台函数列表会有提示。
## 9. 常见问题

**Q：提交服务器配置时提示「token验证失败」**
① 函数没部署 ② `WECHAT_TOKEN` 和网页 Token 不一致 ③ 函数 URL 填错（多/少斜杠）
④ 环境变量改了没点「部署」

**Q：发「查电费」没反应**
① 服务器配置没**启用** ② 自动回复里有规则抢答了（去清空）
③ 日志查询里看有没有 `[wx] POST` 记录；没有就是微信没打到你的函数

**Q：回复「公众号暂时无法提供服务」**
函数 5 秒内没返回。看日志是不是卡在查询；可把环境变量 `LOW_THRESHOLD` 先不管，
重点看 `[query] ... 失败`：若是网络问题，检查 VPC 是否误开。

**Q：会收到重复回复吗**
微信在超时后会重试（最多 2 次）。我们正常 0.3–1 秒返回，基本不会触发。

**Q：订阅号能主动推送吗**
不能（个人主体未认证）。所以定时推送仍走 PushPlus；订阅号只负责"你问它答"。

**Q：订阅号消息也是折叠在小窗里？**
是的，公众号消息都会折叠进「订阅号消息」。这是微信机制，改不了。
如果一定要像聊天一样可见，只能用「机器人会话」（OpenClaw 那套，需要一台常开机器）。
