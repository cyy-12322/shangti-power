## 二、知乎 / 贴吧 / 校园论坛（长文）

**标题建议：**
- 《给上体宿舍写了个查电费的小工具：开机自动弹窗，剩多少度一眼看到》
- 《宿舍电费总是突然用完？我写了个 Windows 小工具来解决》

**正文：**

> 上体的宿舍电费要在公众号里一层层点进去才能看到，每次出门前想确认一下都挺麻烦。
> 所以写了个 Windows 桌面小工具「宿电监测」，分享给同样有需要的同学。
>
> **它做什么**
>
> - 开机自动查一次电费，弹个小窗口显示剩余度数
> - 电量低于设定值（默认 20 度）界面变红，提示该充值了
> - 记住姓名/学号后，点「去缴费」自动带入房间和姓名，直接进学校官方缴费页
> - 设置里可以换房间、改提醒阈值、开关开机自启
>
> **几个特点**
>
> - 免登录：只调用学校公开的余额查询接口，不需要账号密码
> - 极轻量：C# 自绘界面，单文件约 270KB，内存约 35MB，关掉就完全退出
> - 免运行时：只用 Windows 自带的 .NET Framework，不用装 Python/Node
> - 开源免费：源码在 GitHub，MIT 协议
>
> **注意**
>
> - 非官方工具，数据来自学校公开页面，仅供参考
> - 线上缴费到账有延迟，最长约 3 小时属正常，不要重复支付
> - 未购买代码签名证书，首次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可
>
> 下载（Windows 10/11）：
> https://github.com/cyy-12322/shangti-power/releases/latest
>
> 有 bug 或想加功能，欢迎在 GitHub 提 Issue，或者直接回帖告诉我。
